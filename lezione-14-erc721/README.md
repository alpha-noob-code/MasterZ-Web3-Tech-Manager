# Lezione 14 - NFT ERC721

Collezione NFT fatta con OpenZeppelin (ERC721 + URIStorage).

- Nome: MasterZ NFT
- Simbolo: MZNFT
- `safeMint(indirizzo, uri)` crea un nuovo NFT, solo l'owner
- immagine e metadati caricati su IPFS con Pinata, esempio in `metadata/0.json`

Deploy e test su Remix (Remix VM).
